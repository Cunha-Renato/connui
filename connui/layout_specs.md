# Engine Specifications

****
### Order
- **Front-Back:** The same order as the **Widgets** are in.
- **Back-Front:** The reverse order as the **Widgets**.

****
### Input
- **InputEvent:** Events generated by user input.
- **Capture:** If the **Widget** has priority over mouse events.
- **Focus:** If the **Widget** has priority over keyboard events.
- **Order:** **Widgets** get input in **Back-Front** order, if a **Widget** returns a response the event will be consumed.

****
### Positioning
- **Dynamic:** The position is dictated by the parent. The draw order is **Front-Back**. It is the only one that can contribute to the parent's **Size**.
- **Pinned:** The position is dictated by the given **Position**. **Pinned** **Widgets** get draw first compared to **Dynamic** ones, and the draw order between them is **Front-Back**. They are the first of the children to get **InputEvent** after the ones that have **Capture** or **Focus**.
- **Overlay:** Similar to **Pinned** with the exception that all **Overlay** get's drawn later than any other **Widget**. They are the first ones in the entire pipeline to get **InputEvent** after the ones that have **Capture** or **Focus**.

****
### Sizing
- **Absolute:** Treats the given values as absolute and doesn't get resized.
- **Fit:** Tries it's best to contain all of it's children, does't shrink.
- **Fill:** Behaves like **Fit** with the following exceptions: it can shrink and atemps to occupy the available space inside it's parent, has 0 size to begin, unless given an initial size.
